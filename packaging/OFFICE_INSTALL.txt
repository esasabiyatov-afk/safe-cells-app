СЕЙФОВЫЕ ЯЧЕЙКИ — ПЕРЕНОС В ОФИС

1. Не заменяйте и не удаляйте общую папку с базами.
2. Закройте приложение на всех рабочих компьютерах.
3. Скопируйте всю эту папку на локальный диск рабочего компьютера.
4. Запустите configure-database.cmd и выберите существующую общую папку,
   где находятся vault_cells.sqlite3, vault_archive.sqlite3 и templates.
5. Если старая база имеет схему 11, один раз на одном компьютере запустите
   migrate-to-v12.cmd. Перед изменением автоматически создаётся резервная копия.
6. Запустите create-shortcut.cmd. Сотрудники работают через созданный ярлык.

ПЕРВИЧНЫЙ ПЕРЕНОС ИЗ EXCEL

- Войдите как администратор и откройте «Дополнительно» →
  «Первичный перенос старых договоров».
- Проверьте XLSX без записи.
- Войдите в АБС и нажмите «Найти клиентов и телефоны в АБС».
- Если найдено несколько одинаковых ФИО, выберите нужного клиента.
- Номер счёта берётся из Excel и не заменяется счётом из АБС.
- После проверки поставьте подтверждение и выполните перенос.

ПОСЛЕ ПЕРЕНОСА

- Кнопка «Обновить клиентов из АБС» обрабатывает только активные договоры,
  в которых уже сохранён ID клиента АБС.
- Массово обновляются ФИО, оба телефона и данные ID-карты.
- Номер счёта массовое обновление не меняет.
- При напоминании сначала выберите нужный номер; только затем откроется
  WhatsApp Web.

Сеанс АБС по умолчанию — 60 минут. Его длительность меняется в настройках,
в разделе «Общие параметры». Логин и пароль АБС нигде не сохраняются.

Папка сборки не содержит рабочей базы и не меняет её до явной миграции или
подтверждённого переноса Excel.
