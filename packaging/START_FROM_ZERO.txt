СЕЙФОВЫЕ ЯЧЕЙКИ — НАЧАТЬ С НОВОЙ БАЗЫ

В комплекте две папки:

- APP — приложение для рабочего компьютера;
- NEW_SHARED_DATABASE — новая общая база без договоров.

Порядок запуска:

1. Скопируйте папку APP на локальный диск рабочего компьютера.
2. Скопируйте ВСЮ папку NEW_SHARED_DATABASE в общую сетевую папку банка.
   Внутри должны остаться обе базы и каталог templates.
3. В папке APP запустите configure-database.cmd и выберите скопированную
   сетевую папку NEW_SHARED_DATABASE.
4. Запустите create-shortcut.cmd. После этого используйте ярлык
   «Сейфовые ячейки» на рабочем столе.
5. Войдите как администратор, задайте ФИО и пароль, затем выполните
   первичный перенос договоров из Excel через настройки.

Новая база содержит 126 свободных ячеек, исходные тарифы и шесть шаблонов
документов. Активных договоров, архивных договоров и данных клиентов в ней нет.

При переносе из Excel номер счёта остаётся из Excel. После привязки клиентов
по ID АБС кнопка «Обновить клиентов из АБС» массово обновляет ФИО, оба
телефона и данные ID-карты; номер счёта она не меняет.
