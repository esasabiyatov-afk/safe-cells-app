СЕЙФОВЫЕ ЯЧЕЙКИ — ПОРТАТИВНЫЙ ЗАПУСК

1. Папку можно разместить локально на рабочем компьютере без установки Python.
2. Запустите configure-database.cmd и выберите общую папку, в которой сразу
   находятся обе базы и каталог templates. config.json будет создан автоматически.
3. Запустите create-shortcut.cmd один раз от имени обычного пользователя.
4. После этого сотрудник использует ярлык «Сейфовые ячейки» на рабочем столе.

config.example.json оставлен только для администратора. Вручную редактировать
config.json обычному сотруднику больше не требуется.

Файл safe-cells.exe не переносите на сетевой диск: на сетевом диске общими являются
только базы, шаблоны, резервные комплекты и служебные блокировки экземпляров.

Подробная проверка описана в docs/DEPLOYMENT_GUIDE.md репозитория проекта.
