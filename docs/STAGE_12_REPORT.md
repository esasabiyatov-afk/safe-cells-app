# Отчёт по этапу 12

Дата: 21 июля 2026 года.

## Результат

Переносимая Windows-сборка технически готова. Создаётся один оконный `safe-cells.exe` без консоли и установки Python. Сотрудник запускает его ярлыком «Сейфовые ячейки»; EXE читает `config.json` рядом с собой, проверяет существующую общую папку, занимает свободный порт только на `127.0.0.1` и открывает браузер.

Каждый процесс имеет собственный случайный токен и обезличенные идентификаторы вкладок. Обновление страницы не завершает процесс. Главная страница и журнал могут работать одновременно; закрытие одной вкладки не останавливает оставшуюся. Закрытие последней вкладки или кнопка «Выйти» завершает только соответствующий локальный сервер. Ни токен, ни сетевой путь, ни персональные данные в служебный файл готовности не записываются.

## Автоматически проверено

- полный строгий набор: `289 passed` на Python 3.14.6;
- три одновременных локальных сервера на трёх разных свободных портах;
- остановка одного сервера без влияния на два других;
- обновление вкладки отменяет отложенное завершение;
- неверный токен и неверный идентификатор вкладки отклоняются;
- отсутствующая общая папка или каталог `templates` не создаются и дают безопасную ошибку;
- PyInstaller 6.21.0 формирует Windows GUI EXE без консольной подсистемы;
- EXE запускается из изолированной папки с очищенными `PYTHONPATH`, `PYTHONHOME` и `PATH` без Python;
- собранный EXE проходит health, 126 ячеек, выбор сотрудника, калькулятор, открытие, генерацию/скачивание DOCX, продление, закрытие, журнал, Excel и минимум три резервных комплекта;
- HTML собранной версии не содержит внешних HTTP/HTTPS-ресурсов;
- в локальном браузере проверены рабочая сетка, кнопка «Выйти», журнал без горизонтального переполнения, обновление страницы и две вкладки;
- `pip check`, компиляция, `git diff --check` и финальная проверка Git выполняются перед коммитом.

## Не выполнено без внешнего стенда

- фактический UNC-путь всё ещё является Q-006 и намеренно не записан;
- нет приёмки на реальном тестовом SMB-томе с 1–3 отдельными компьютерами и реальными правами пользователей;
- нет результата проверки банковским антивирусом и политиками запуска неподписанного EXE;
- нет финальной визуальной/юридической сверки пяти утверждённых DOCX в Microsoft Word;
- пользователь ещё должен явно принять этап после ручной проверки.

Поэтому этап 12 технически завершён, но производственный допуск пока не заявлен.
