# Руководство администратора

## Статус документа

Это архитектурная версия. Точные команды и скриншоты появятся после реализации и сборки.

## Безопасные принципы развёртывания

- На каждом компьютере в папке установки находится собственный скрытый `safe-cells.exe` и локальный конфигурационный файл.
- На рабочем столе создаётся веб-ярлык «Сейфовые ячейки»; сотрудник использует только его.
- В конфиге указывается общая папка; реальный UNC-путь и пароли не коммитятся.
- В общей папке находятся `vault_cells.sqlite3`, `vault_archive.sqlite3`, `templates` и `backups`.
- Обе БД обязаны находиться на одном сетевом томе.
- Обычный запуск не создаёт отсутствующую базу. Первичная инициализация — отдельное подтверждённое действие.
- WAL запрещён; файловый атрибут Windows «Только чтение» не меняется.

## Первичная настройка — будущая процедура

1. Создать отдельную тестовую общую папку без реальных данных.
2. Проверить права чтения/записи и блокировки SMB с компьютеров сотрудников.
3. Выполнить явную инициализацию двух баз один раз.
4. Задать денежные настройки и административный пароль.
5. Установить утверждённые DOCX-шаблоны.
6. Запустить проверку с 1–3 экземплярами на тестовых данных.
7. Убедиться, что запуск с рабочего стола открывает браузер без окна консоли и без ручного поиска `.exe`.

## Бэкапы

После каждой подтверждённой записи приложение создаёт через SQLite Backup API один комплект из двух баз, проверяет его и сохраняет манифест. Хранятся последние 30 валидных комплектов. Обычное копирование активных файлов во время работы запрещено.

## Восстановление

Восстановление никогда не запускается автоматически. Администратор должен:

1. Закрыть все экземпляры приложения.
2. Сохранить повреждённые файлы отдельно.
3. Выбрать один полный проверенный комплект.
4. Восстановить обе базы вместе.
5. Выполнить проверку целостности и тестовый запуск.

Точные кнопки/команды будут добавлены после этапа 11. До этого документ не является инструкцией для производственного восстановления.

## Нерешённые входные данные

- валюта, точность и сумма залога;
- фактический UNC-путь;
- реальные DOCX-шаблоны;
- правила возврата при закрытии.
