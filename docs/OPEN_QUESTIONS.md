# Открытые вопросы владельцу требований

Здесь находятся только вопросы, на которые нельзя безопасно ответить по имеющимся документам. Технические детали команда решает самостоятельно.

## Вопросы, влияющие на деньги или даты

## Вопросы по юридическим документам

### Q-004. Реальные DOCX-шаблоны и обязательные реквизиты

Нужны утверждённые банком DOCX-файлы. Точный набор полей определяется непосредственно по их плейсхолдерам; дополнительные банковские реквизиты не придумываются. Вопрос блокирует только завершение этапа документов, а не ранние технические этапы.

### Q-005. Официальные названия файлов и комплект документов

Для занятия, продления и каждого вида закрытия нужно подтвердить, какие именно типы документов обязательны и как они официально называются. До получения шаблонов будут только тестовые шаблоны механизма, явно помеченные как тестовые.

## Вопрос развёртывания

### Q-006. Реальный путь к общей сетевой папке

Путь понадобится только для тестового развёртывания. Его нельзя коммитить; он будет находиться в локальном конфигурационном файле на каждом компьютере. До этого все проверки выполняются во временной локальной папке.
